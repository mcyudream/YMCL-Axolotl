# 域首页

域管理员在插件管理后台「YMCL 适配器 → 域首页」统一配置并发布背景、轮播、音乐、焦点与默认服务器，管理路由为 `/platform/plugins/ymcl-adapter/admin/chrome-home`，需要 `plugin:ymcl-adapter:design` 权限。启动器第二页保留管理员对信息卡片布局的编辑、发布和锁定，不提供媒体配置入口。成员切换域后回到首页；已启用的域首页优先于个人的简洁首页和在线启动时的默认页面选项。

配置只涉及域管理员，不加入面向所有新成员的首次引导。成员首页负责展示、角色切换与进服；个人首页的既有小组件引导继续沿用。沉浸式第一页不显示布局控件，第二页使用原有小组件编辑交互和功能提示，供已登录成员在域允许时自定义本机视图。管理员编辑沿用相同的卡片工具与明确的发布按钮，仅管理员可见，不改变新成员的首次使用流程，无需增加全局引导步骤。

## 首页与信息页

- 域首页分为「首页」与「域信息」两页，右侧保留两个小型分页指示，选中页显示为长点，悬停或聚焦时提示页名，支持点击切换。两页为分页指示预留侧边空间，不再占用整条底栏。首页展示轮播、域焦点和快捷进服；域信息复用管理员在插件后台发布的原卡片配置，并应用成员已保存的本机覆盖，不混入个人首页卡片。
- 域信息页恢复原有小组件编辑入口，支持增删、拖拽、尺寸、网格与自由布局、恢复默认和完成保存。域未锁定布局时，当前域已登录成员可编辑自己的视图；空卡片布局也可进入编辑后添加。成员编辑以「完成」保存本机覆盖，管理员以「编辑域布局」读取域配置，并显式发布或取消。管理员可编辑已锁定的域布局；普通成员遇到锁定或退出登录时收起编辑入口并结束草稿。
- 首页高度由父级视口限定，域焦点与欢迎介绍只使用启动区之外的剩余空间。长新闻和公告在焦点面板内部滚动，启动按钮、下载详情与进度条保持在底部可见；焦点内容不增加整页高度。
- 第一页左下角显示当前 Minecraft 角色的头像、名称和切换入口，复用侧栏的域角色选择与账号保存流程。角色列表只属于当前域，切换后欢迎语和卡片使用同一个角色名称；切域或退出登录会作废未完成的角色请求。
- 向下滚轮进入域信息，向上返回首页。页面内容超出窗口时先滚动内容，到达边缘后下一次滚轮手势才切页；卡片内部的滚动列表、输入控件和弹层自行处理滚动。触控板连续惯性只触发一次切页。
- 两页在首页挂载期间各自保留滚动位置；首次进入信息页才加载卡片，之后保持挂载。翻页不重建首页，服务器选择、下载、启动与音乐状态持续保留。分页选择由内存中的 Pinia 状态按域与账号记录：离开首页再回来恢复当前页，切换到首次访问的域或账号默认第一页；重启启动器后清空分页记忆，不写入本地持久化配置。
- 翻页时背景留在原位，首页内容与信息层以渐隐和小幅位移交接，信息层使用主题底色与背景模糊保证卡片可读。切到信息页时暂停背景自动轮播，返回后继续；音乐和启动任务持续运行。过渡时长为 640 毫秒，滚轮锁定覆盖整个动画与后续惯性；系统减少动态效果时取消过渡。这些入口承担成员的上下文提示，无需加入个人首页小组件的首次引导。

## 权限与操作范围

- 域首页配置、媒体上传、发布与清除托管均要求 `plugin:ymcl-adapter:design`，宿主超级管理员的 `*` 授权同样有效。插件管理路由、表单动作与服务端写接口共同执行权限检查，登录本身不授予管理员权限。
- 普通成员读取已发布的首页，并按各数据源权限查看焦点和启动服务器；音乐播放、音量和轮播翻页只影响当前设备。
- 卡片首页与沉浸式首页的信息页未锁定时，当前域已登录成员可保存本机布局覆盖。该操作不发送域发布请求；管理员锁定布局后，本机覆盖不再生效，成员编辑操作也不可用。
- 当前域的设计权限授予管理员域卡片的发布与锁定操作，通配授权沿用统一权限判断；普通成员、匿名用户、其他域会话不拥有这些操作。发布只更新卡片布局并保留轮播、音乐、焦点、未知卡片与扩展字段；已存在卡片的文案、目标与数据绑定随编辑结果更新。
- 切换域、切换登录用户、退出登录或权限失效时，结束当前编辑并作废未完成的请求，防止旧草稿保存到其他域。发布或锁定前回读最新文档，写入时校验目标域；保存失败保留当前草稿。

启动时必须先完成底层状态初始化，再读取当前域、会话与首页配置；默认页面跳转等待域初始化，避免提前读取失败后停留在个人域。

## 可配置内容

- 欢迎标题、欢迎说明和默认服务器。
- 最多 12 张背景图，可排序、移除。轮播文案可选统一标题与介绍，或为每张图填写独立标题和说明；独立文案为空时使用欢迎文案，切换模式保留两套内容。
- 轮播间隔 3–60 秒，淡入切换；支持手动翻页、分页圆点和暂停。鼠标或焦点停留在轮播控件上、窗口不可见时暂停自动切换；系统减少动态效果时关闭自动轮播和过渡。
- 多个域数据源组成域焦点，默认汇总各来源，支持切换分类、列表分页、日期、置顶和详情。沿用域权限和数据动作；单个来源出错时可单独重试。
- MC 新闻插件贡献 `mc-news.news`，使用现有新闻缓存与摘要，提供原文入口；需要登录及 `plugin:mc-news:use` 权限。
- 域公告由插件后台独立的「域公告」列表维护，管理路由为 `/platform/plugins/ymcl-adapter/admin/announcements`。支持新增、编辑、删除、草稿、发布和置顶，需要设计权限；成员数据源 `ymcl-adapter.announcements` 仅返回已发布公告，匿名请求为空集。草稿不写入成员可读的首页文档。
- 背景音乐上传、曲目名、默认音量和自动播放。音频循环播放，成员可暂停和调节音量；自动播放受限时提示手动播放，离开首页停止播放。
- 首页显示当前服务器的图标、名称与状态；多个服务器时提供明确的「切换服务器」按钮，在页面内展开选项网格，不弹出选择框。服务器较多时支持搜索和列表内部滚动，选择后更新当前服务器并收起列表。快捷操作按真实状态显示下载、更新、启动、运行中或错误；没有任务时保持简洁，进行任务时展开进度、文件结果和重试。下载、安装与更新直接在首页执行，不打开进服弹窗；无整合包服务器可直接选择本地实例。
- 已安装实例启动前重新检查版本与连接地址；发现更新时先在首页完成更新。进度按下载任务 ID 或整合包与实例 ID 匹配，未知总量显示不确定进度。被跳过的文件保留本地副本，并按实际结果提示。
- 下载与更新的生命周期由共享任务状态按域、账号和服务器管理，不随首页组件卸载而结束。离开首页再回来恢复所选服务器及对应任务的实时进度；离开期间完成或失败也保留结果并重新检查实例状态，禁止重复提交正在运行的任务。原版游戏下载同样恢复原任务，返回页面不会自动启动游戏。

图片和音乐在插件管理页使用带上传图标的上传控件，不要求管理员填写地址。图片支持 PNG、JPG、GIF、WebP，单张不超过 10 MB；音乐支持 MP3、OGG、WAV，单个不超过 30 MB。上传经 `POST /v1/admin/home/media` 使用插件设计权限，由插件文件存储托管并提供稳定公开地址；音频读取支持 GET、HEAD、单段 Range。上传只更新编辑草稿，发布后才影响成员首页；移除引用或清除托管不会删除媒体文件。

## 适配器契约

沿用 YAP 的 `GET/PUT /chrome/home`，在原有首页文档中增加 `landing`。适配器必须原样保存该字段，并将它包含在成员可读的 `manifest.home` 中。发布后沿用 `manifest.updated` 通知刷新。

```json
{
	"schemaVersion": 1,
	"cards": [],
	"landing": {
		"enabled": true,
		"title": "欢迎来到梦屿",
		"description": "下一段旅程，从这里开始。",
		"copyMode": "individual",
		"slides": [
			{ "id": "sunset", "image": "/media/sunset.webp", "title": "", "description": "" },
			{ "id": "village", "image": "/media/village.webp", "title": "村庄的新故事", "description": "一起建造属于我们的世界。" }
		],
		"interval": 8,
		"overlay": 35,
		"focusSources": ["ymcl-adapter.announcements", "mc-news.news"],
		"featuredServerId": "survival",
		"music": { "url": "/media/home.ogg", "title": "归途", "autoplay": false, "volume": 35 }
	}
}
```

`overlay`、`volume` 单位为百分比。`copyMode` 为 `shared` 或 `individual`，未提供时默认 `individual` 以保留既有逐图介绍。`focusSources` 使用 manifest 声明的数据源 ID；`featuredServerId` 使用域服务器 ID。关闭或缺少 `landing.enabled` 时沿用卡片首页，切换模式保留卡片配置。

插件管理页发布后会回读配置。如果配置未完整保存，会保留编辑草稿并显示错误。重新发布卡片布局也必须保留 `landing` 和其他扩展字段。
